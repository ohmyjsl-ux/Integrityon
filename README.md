# 청렴ON 2.0 — 청렴, 자격이 되다

중·고등학생이 교사 PC와 학생 휴대폰을 실시간으로 연결해 진행하는 47분 참여형 청렴교육 프로그램입니다.

## 수업 흐름

1. **수험등록(3분)**: QR 접속, 6자리 참여코드, 학생 이름 등록
2. **STEP 1 청렴 순간판단 TEST(8분)**: 5문항, 문항당 10초, 선택 즉시 제출
3. **STEP 2 청렴 시뮬레이터 : 선택의 결과(12분)**: 분기형 3개 상황, 결과 확인 후 1회 재선택
4. **STEP 3 FINAL 현장미션(17분)**: 4인 1팀, 디지털 사건파일·증거 분석, 3단계 판정과 개선조치 2개 선택
5. **STEP 4 청렴능력 자격증(7분)**: 개인 실천서약, 점수·자격판정, 디지털 자격증 저장

## 교사용 기능

- 수업방 개설, QR 및 학생 링크 생성
- 새로고침 후 진행 중 수업방 자동 복구
- STEP 1의 10초 동시 타이머와 답안 자동 잠금
- 실시간 응답 분포 및 시뮬레이터 선택 변화 집계
- 등록 순서 기준 4인 1팀 자동편성
- 모둠별 현장미션 제출현황·평균점수 확인
- 학생별 결과 CSV 저장
- 수업 종료 시 이름·응답·서약 전체 삭제

## 학생용 기능

- QR 재접속 및 새로고침 후 응시 화면 자동 복구
- 10초 순간판단, 선택 결과 확인, 1회 재선택
- 앞선 선택에 따라 달라지는 다음 시나리오
- 모둠별 사건파일 토론 후 팀 합의안 개별 제출
- 개인 실천서약, 점수표, 디지털 자격증 이미지 저장

## 자격판정

- 배점: 순간판단 30% + 시뮬레이터 40% + 현장미션 30%
- 전 과정을 완료하면 기본 **청렴 서포터**
- 종합 85점 이상, 시뮬레이터 80점 이상, 현장미션 80점 이상이면 **청렴 리더**
- 실제 국가기술자격이 아닌 교육용 청렴역량 인증

## GitHub Pages 적용

1. 이 폴더의 파일과 하위 폴더를 저장소 최상위에 그대로 업로드합니다.
2. Firebase Authentication에서 **Anonymous** 로그인을 활성화합니다.
3. Realtime Database를 만든 뒤 `firebase.rules.json`의 규칙을 게시합니다.
4. `js/firebase-config.js`에 Firebase 웹 설정값을 입력합니다.
5. GitHub Pages를 저장소 기본 브랜치의 `/(root)`에서 배포합니다.
6. `teacher.html`에서 수업방을 열고 학생에게 QR을 안내합니다.

자세한 설정 순서는 `SETUP.html`에서 확인할 수 있습니다.

## 개인정보 운영 유의사항

- 전화번호·이메일은 수집하지 않습니다.
- 학생 이름은 출석 확인과 자격증 표시에만 사용합니다.
- 실제 운영 전 학교의 개인정보 처리 기준을 확인합니다.
- 수업 종료 후 교사가 반드시 **수업방 종료·삭제**를 눌러 해당 수업 데이터를 삭제합니다.
