# 청렴ON 3.0 — 청렴, 자격이 되다

한국산업인력공단의 자격검정 방식을 교육적으로 차용한 중·고등학생 47분 참여형 청렴교육 프로그램입니다. 교사 PC와 학생 휴대폰을 실시간으로 연결하며, 종이 활동지 없이 진행할 수 있습니다.

## 수업 흐름

1. **수험등록·검정안내(3분)**: QR 접속, 6자리 참여코드, 학생 이름 등록
2. **STEP 1 필기시험(10분)**: 생활·디지털 청렴판단 6문항, 문항당 12초
3. **STEP 2 실기시험(14분)**: 투명구매 절차 배열, 100점 평가기준표 설계, 전자정산서 위험신호 탐지
4. **STEP 3 조별과제(15분)**: 4인 1조, 역할별 비밀증거 감식, 구두 브리핑, 합동심리, 재발방지 프로토콜 설계
5. **FINAL 종합판정(5분)**: 개인 실천서약, 종합점수·강약점 환류, 디지털 인증서 저장

각 시험은 100점으로 독립 채점되며 시험 종료 직후 개인 성적표, 강점역량, 보완역량과 다음 행동 문장을 제공합니다.

## 교사용 기능

- 수업방 개설, QR 및 학생 링크 생성
- 필기시험 동시 타이머·답안 잠금·해설 공개
- 실기작업별 제출률과 평균점수 확인
- 등록 순서 기준 4인 1조 및 4가지 감사역할 자동편성
- 조별과제 제출현황·조별 평균 확인
- 6대 청렴역량 학급 진단과 학생별 3개 시험 점수 확인
- 강점·보완역량·실천서약을 포함한 CSV 결과 저장
- 수업 종료 시 이름·응답·서약 전체 삭제

## 평가체계

- 필기시험 30% + 실기시험 35% + 조별과제 35%
- 종합 60점 이상: **청렴 서포터**
- 종합 85점 이상이면서 실기·조별과제 각 75점 이상: **청렴 리더**
- 60점 미만: **재도전 권장** 및 개인 보완역량 환류
- 실제 국가기술자격이 아닌 교육용 청렴역량 인증

## GitHub Pages 적용

1. 이 폴더의 파일과 하위 폴더를 저장소 최상위에 그대로 업로드합니다.
2. Firebase Authentication에서 **Anonymous** 로그인을 활성화합니다.
3. Realtime Database의 Rules 화면에 `firebase.rules.json` 내용을 붙여넣고 게시합니다.
4. `js/firebase-config.js`에 Firebase 웹 설정값을 입력합니다.
5. GitHub Pages를 기본 브랜치의 `/ (root)`에서 배포합니다.
6. `teacher.html`에서 수업방을 열고 학생에게 QR을 안내합니다.

기존 2.0 규칙을 사용 중이라면 구조화된 실기·조별과제 답안을 저장할 수 있도록 새 `firebase.rules.json`을 반드시 다시 게시해야 합니다.

## 개인정보 운영 유의사항

- 전화번호·이메일은 수집하지 않습니다.
- 학생 이름은 출석 확인과 교육용 인증서 표시에만 사용합니다.
- 실제 운영 전 학교의 개인정보 처리 기준을 확인합니다.
- 수업 종료 후 교사가 반드시 **수업방 종료·삭제**를 눌러 해당 수업 데이터를 삭제합니다.
