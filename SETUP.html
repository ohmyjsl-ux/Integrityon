ONE-TIME SETUP

PC ↔ 학생 휴대폰 실시간 연결 설정

청렴ON 2.0은 GitHub Pages 같은 정적 웹호스팅과 Firebase Realtime Database를 결합합니다. Firebase 웹 설정값은 비밀번호가 아니라 프로젝트 식별정보이며, 실제 접근 권한은 아래 보안규칙과 익명 인증으로 제한합니다.

  1. Firebase Console에서 새 프로젝트를 만듭니다.
  2. Authentication → Sign-in method → Anonymous를 활성화합니다.
  3. Realtime Database를 생성합니다.
  4. 프로젝트 설정 → 웹 앱 추가에서 Firebase config를 확인합니다.
  5. js/firebase-config.js의 YOUR_... 값을 실제 값으로 바꿉니다.
  6. 처음 설치하거나 보안규칙을 갱신할 때 Realtime Database → Rules에 firebase.rules.json 내용을 붙여넣고 게시합니다.
  7. 이 폴더 전체를 GitHub Pages에 업로드합니다.
  8. PC에서 teacher.html → 수업방 개설 → 표시된 QR을 학생이 촬영하면 실시간 수업이 시작됩니다.
학생 개인정보 최소화
전화번호·이메일은 받지 않고 학생 이름, 학교급, 익명 사용자 ID, 응답과 실천서약만 사용하도록 설계했습니다. 실제 운영 전 학교의 개인정보 처리기준을 확인하고, 수업 종료 후 교사가 수업방 삭제 버튼으로 데이터를 삭제하세요.

firebase-config.js 예시 

window.CHEONGRYEOM_FIREBASE={
  apiKey:"...",
  authDomain:"...firebaseapp.com",
  databaseURL:"https://...-default-rtdb.firebaseio.com",
  projectId:"...",
  appId:"..."
};
